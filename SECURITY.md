# Security policy

Use a supported, patched Next.js release. This repository uses Next.js 16.3.3. Never submit passwords, API keys, tokens, payment data, or other secrets to a hosted form endpoint.

`NEXT_PUBLIC_*` values are browser-visible. Keep server-only variables unprefixed, restrict SmartFormify endpoints to expected domains, and regenerate an endpoint key if it is abused. Report repository vulnerabilities privately to the maintainers rather than opening a public issue with exploit details.
