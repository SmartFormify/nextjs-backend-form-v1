# Pages Router Api Route

This Next.js-specific tutorial explains the pattern, configuration, and accepted-success/error behavior. Read the runnable source in `app/` and use the public endpoint only from expected domains.

## Key decision

Use direct browser submission for simple forms. Add a Server Action or Route Handler only when you have real server-side work to perform.
