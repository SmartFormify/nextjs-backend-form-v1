# Next.js Beta signup

A distinct, accessible App Router beta signup example. It collects: **name, email, role, feedback interest**.

Use a public SmartFormify endpoint with domain restrictions. This is a request/submission form, never an authentication or payment flow.

## Technique

Native HTML POST keeps this example copyable and works without custom client JavaScript. Add the endpoint to the form action and test success behavior from an allowed domain.
